# Directory selection path

In Directory guides mode, the selected node and every visible ancestor receive darkened handles. The **Ancestor titles** toggle (on by default, session-only) optionally highlights ancestor titles using the same pale green as cell selection. The selected title gets no additional highlight; its cell selection remains visible. The connector route from the visible root to the selected node turns dark green. Descendants and unrelated branches keep their ordinary styling; the route stops at the selected handle. Focused subtree views begin at their visible root. The original guide mode is unchanged.

`web/App.tsx` derives the path from `nodePath(shown, selectedId)` on every render. `on-path` marks its nodes, `path-ancestor` marks rows whose downward connector continues toward the selection, and `before-path` marks earlier siblings whose vertical trunk is traversed. Earlier sibling handles, titles, and horizontal connectors remain unhighlighted. Both their full-height stem and overlaid upper-half junction must be darkened to avoid pale gaps. `web/style.css` scopes the visual rules to `.directory-guides`, with direct-child selectors to avoid coloring unrelated descendants.

Selection uses the existing keyboard, pointer and editing focus behavior. Highlighting changes no task data or history. It supports plain rings, leaf drawings, checked nodes and collapsed branches; a selected collapsed branch highlights only its incoming path.

Pale horizontal arms at earlier siblings start at the right edge of the 2px dark trunk, with their width shortened by 2px to preserve the endpoint. This prevents the arm from overpainting a tiny strip across the highlighted vertical line. The junction fix was visually checked in Firefox and passed the focused browser regression and production build.

Validation: all 33 automated tests and production build pass. A focused Firefox regression covers both upper and lower trunk segments at siblings of ancestors and the selected node, ancestor-only coloring, and the title toggle. Firefox verified trunk continuity through an earlier expanded sibling, isolated sibling styling, the stopping point, title highlighting, focused views, mode switching and unchanged stored data; desktop and narrow screenshots inspected.
